# ORGOS Company Transfer - React + Vite

Standalone frontend-only React + Vite project.

## Features
- Add Company button in the left column
- Enter a company name and add it to Available Companies
- Duplicate company validation
- Company count updates automatically
- Select a company and move it with `→`
- Select a company and move it back with `←`
- Responsive layout
- No backend, database, API, or UI library

## Run
```powershell
npm install
npm run dev
```
